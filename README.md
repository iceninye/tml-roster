# TML Roster · 我的更表

屯馬綫 Duty Sheet 個人版：貼上自己嘅 roster 一次，之後逐日、逐週睇自己嘅更份，包括上班、下班、地點、用膳同全日行程。

**你嘅更表只會儲存喺自己部機嘅瀏覽器（`localStorage`），唔會上傳。** 呢個 repo 入面冇任何人嘅 roster。

## 快速開始

1. 打開網頁，首次會見到「設定我的更表」。
2. **第 1 步：貼上 roster**，或者撳「由檔案匯入」揀 .csv／.tsv／.txt 檔。由 Excel 直接複製貼上都得（冇行號都可以）。貼上嘅同時，下面「即時預覽」會顯示讀到嘅內容同有問題嘅行。
3. **第 2 步：填今個星期係第幾行。** 之後每過一個星期會自動跳去下一行，行完最後一行就返去第一行。
4. 撳「儲存」。主頁會顯示今個星期每一日嘅更份同上下班時間。

之後：

- 主頁最底有「我嘅 roster」表格，顯示你匯入嘅全部行數：今個星期嗰行標紅，今日嗰格有紅框。
- 撳任何一日，睇全日行程。今日會標示你現時做緊乜。
- 特別日子（例如 8022、8023）想換成另一個更份：撳該日，喺「改呢日嘅更份」輸入 `8022131` 之類編號，亦可以還原做預設。
- 換手機之前，去「設定／備份」匯出備份，之後貼返入設定頁就還原到。

## 編更（`plan.html`）

由主頁底「編更」入去。用嘅 Standard Roster 係你喺主頁貼咗嗰份。

1. 揀基準星期（例如 Week 42）同嗰個星期組員嘅行號（例如 `31-40, 55-70`）。之後每個星期每位組員自動跳去下一行。
2. 喺表入面每位組員嗰行填名，同撳更類揀想做嘅更：死早（06:30 前上班）、早、中、夜、死夜（00:30 後下班），可以揀多個。
3. 撳「按偏好自動編排」，或者「由本週起連續 N 週」編多個星期。只會喺同一日、組員嗰幾行嘅更份之間對調，休息日同假期唔郁；休息唔夠鐘（預設 11 小時）會標紅。
4. 拖放兩格（或者撳一格再撳同日另一格）就對調；撳一格可以改嗰日。手動改過嘅格有 📌，再自動編排都會保留。手機要長按一下先可以拖。
5. 表下面係「積木區」：將更份拖入去暫放，再拖去同日嘅格仔（原本嗰格嘅更份會返去積木區）。自動編排後冇人接嘅更份亦會放喺度。HC（待定）嘅格自動編排唔會郁，你可以自己改或者放積木入去。

組員名、偏好同編更結果只存喺呢部機，可以喺「設定／備份」匯出／匯入，亦可以匯出本週 CSV 貼返入 Excel。

## Roster 要貼成點樣

每行代表一個星期，由週一至週日共 7 格。行頭可以有行號。用逗號、Tab 或空格分隔都得，標題行會自動略過。

```
1,1101101,1101102,RD,1101104,1101105,6091101,RD
2,AL,AL,AL,SH,SH,RD,RD
```

每一格可以係：

| 格內容 | 意思 |
| --- | --- |
| `1101179` | 7 位更份編號，頭 4 位係 Duty Sheet 編號（`1101` 平日、`6091` 星期六、`7091` 星期日） |
| `RD` `AL` `SH` `HC` | 休息日、年假、法定假日、待定 |
| `HSP1` `HSP3` `KSP1`–`KSP4` | 後備更（有上下班時間同地點，冇逐段行程） |

如果某一行格數唔啱，系統會指出邊一行有問題，唔會自己估。如果更份編號喺資料入面冇，會顯示「搵唔到更份 … 資料」。

## 其他資料

- 服務日喺香港時間 04:00 轉日，所以凌晨收工嘅更仍然算前一日。
- 更份資料（`data/duties/`）由公開 repo [TML-traffic](https://github.com/iceninye/TML-traffic) 解析 Duty Sheet 後複製過嚟，唔含人員資料。
- 純靜態網站，冇 build step。網頁經 GitHub Pages 發佈（`.github/workflows/pages.yml`）。

## 開發

```
python3 -m http.server 8000      # 開 http://localhost:8000
node tools/validate_roster.mjs   # roster 邏輯檢查（用虛構 roster）
node tools/validate_plan.mjs     # 編更邏輯檢查（用虛構 roster 同更份）
node tools/sync-duties.mjs       # 由 TML-traffic 同步更份資料
python3 tools/index-to-basic.py Duty.xlsx   # 由 Duty 總表嘅 Index 工作表更新後備更等上下班時間
```

TML-traffic 解析新 Duty Sheet 後，執行 `sync-duties.mjs`，再將 `sw.js` 嘅 `CACHE` 版本加一（新增 sheet 要同時加入 `SHELL`），然後發佈。

版本號同 commit 寫喺 `assets/app.js` 頂部嘅 `BUILD`，每次發佈同步更新 `CHANGELOG.md`。
